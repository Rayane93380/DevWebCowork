# DevWebCowork

Le site est un site de gestion d'espace de cowrking offrant la possibilité de consulter les salles et les ordinateurs disponibles à la réservations ainsi que d'autres fonctionalités.
Le projet est un projet Django et pour lancer le projet il suffit de se placer dans le dossier src depuis le terminal puis d'exécuter la commande : python manage.py runserver et de cliquer sur le lien dans le terminal pour ouvrir la page principale du site. 
Autre commande utile : python manage.py createsuperuser (permet de créer un super utilisateur)
Pour accéder au module administrateur saisir à la fin de l'url de la page principale /admin
